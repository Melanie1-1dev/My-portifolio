# Melanie Ndikubwimana – Portfolio

Modern developer portfolio built with **Next.js 14**, **TypeScript**, **Tailwind CSS**, **Framer Motion**, and **next-themes**.

## About

Portfolio of **Ndikubwimana Melanie**, Software Development student at **Rwanda Coding Academy (S5)**.

Focus areas: Software Development, Web Development, Embedded Systems, AI, Backend, Databases.

## Getting Started

```bash
# Install dependencies
npm install

# Run development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build for production

```bash
npm run build
npm start
```

## Project Structure

```
src/
├── app/                  # Next.js App Router
│   ├── layout.tsx
│   ├── page.tsx
│   └── globals.css
├── components/
│   ├── layout/           # Navbar, Footer
│   ├── sections/         # Hero, About, Skills, Projects, Education, Achievements, Contact
│   ├── ui/               # Reusable Button
│   └── theme-provider.tsx
├── data/                 # projects, skills, socials
├── lib/                  # utils
└── types/
```

## Features

- Dark / Light mode toggle
- Fully responsive (mobile-first)
- Smooth scroll + Framer Motion animations
- SEO metadata
- Clean TypeScript + reusable components
- Project cards with Problem → Solution structure
